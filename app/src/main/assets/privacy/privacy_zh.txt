Etai 应用集隐私政策（C一周通）

生效日期：2026-10-13
发布者：Ch Etang（Etai 应用集）
适用范围：C一周通及同属 Etai 应用集、采用本政策的 Android 应用
完整网址：https://etais.dev/privacy/

一句话说明
这三个应用都是离线、无账号、无服务器的工具。默认不收集、不上传你的个人信息。数据只存在你手机本机；只有你主动导出、分享或备份时，文件才会离开手机。

我们是谁
Etai 应用集是个人开发者发布的开源 Android 应用集合。官网：https://etais.dev/
开源代码见各应用的 GitHub 仓库（C一周通、轻记账、团团记）。

我们处理哪些数据

1. 应用内业务数据（只存本机）
· C一周通：学习进度、错题本、界面语言与主题等偏好
· 轻记账：账本流水、分类、备注、收据图片（若你添加）、界面偏好
· 团团记：团体与成员、事务进度、团费流水、缴费凭证图片（若你添加）、界面偏好

这些数据保存在应用的本机存储中，不会同步到我们运营的云端（我们没有这类服务器）。

2. 你主动导出或分享的内容
当你使用「备份 / 导出 / 复制文案 / 分享」等功能时，会生成 zip、CSV、文本或图片等文件。这些文件只在你选择的保存位置或分享目标中出现。我们不会代你上传。

3. 我们不收集的内容
· 不要求注册或登录
· 不收集姓名、手机号、邮箱、身份证等身份信息
· 不接入广告 SDK、统计分析 SDK、崩溃上报 SDK（以各版本 AndroidManifest 与依赖为准）
· C一周通主清单未声明 INTERNET 权限；合并后的安装清单可能包含 Media3 等依赖库带入的 ACCESS_NETWORK_STATE（用于检测网络状态，本应用不上传你的学习数据）。日常学习不需要联网

权限说明（以安装时系统展示为准）
· C一周通：主清单无 INTERNET；可能合并出现 ACCESS_NETWORK_STATE（来自 Media3 依赖）。课文与演示视频均打包在 APK 内
· 轻记账：主清单无 INTERNET；可能合并出现相机、读取媒体/存储、通知、桌面小组件相关权限，用于收据照片、备份读写与小组件等你启用的功能
· 团团记：主清单无 INTERNET；可能合并出现相机、读取媒体/存储、通知、桌面小组件相关权限，用于凭证照片、备份读写与小组件等你启用的功能

我们不会申请与功能无关的敏感权限。具体列表以安装时系统展示及各仓库源码中的清单为准。

儿童与未成年人
本应用不面向儿童定向收集信息。因数据默认仅存本机且无账号体系，监护人可直接在设备上管理或卸载应用。

数据安全与换机
· 本机数据的安全主要取决于你的设备锁屏与系统安全设置
· 卸载应用通常会删除应用内数据；换机或重装前请先使用应用内备份（如有）
· 正式签名版本与测试版 / 旧签名版可能无法互相覆盖安装；强制卸载会丢数据，请先备份

第三方与开源
· 从 GitHub Releases、酷安、Google Play 等渠道下载时，该渠道可能有自己的下载与账号政策
· 应用依赖的开源库按其许可证使用；我们不会借此引入追踪类服务

政策变更
若本政策有实质变更，我们会更新本页的生效日期，并在合理范围内通过官网或应用更新说明提示。

联系方式
如有隐私相关问题，请通过官网 https://etais.dev/ 或对应 GitHub 仓库的 Discussions / Issues 联系发布者。
