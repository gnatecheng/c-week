Etai Apps Privacy Policy

In one sentence: These apps are offline, account-free, and server-free. By default we do not collect or upload personal information. Data stays on your device; files leave the phone only when you export, share, or back them up yourself.

Effective date: 2026-10-13 · Publisher: Ch Etang (Etai Apps)

Who we are

Etai Apps is a personal developer’s set of open-source Android apps. Website: https://etais.dev/. Source code is on GitHub (c-week, easy-ledger, group-matters).

What data we process

1. In-app data (on-device only)

  • C Week: Learning progress, mistake book, language and theme preferences
  • Easy Ledger: Ledger entries, categories, notes, receipt images (if you add them), UI preferences
  • Group Matters: Groups and members, activity progress, group-fund ledger, payment proof images (if you add them), UI preferences

This data is stored in the app’s local storage and is not synced to a cloud service we operate.

2. Content you export or share

When you use backup, export, copy, or share features, the app may create zip, CSV, text, or image files. Those files appear only where you choose to save or send them. We do not upload them for you.

3. What we do not collect

  • No sign-up or sign-in
  • No identity data such as name, phone number, email, or ID numbers for our services
  • No ad SDKs, analytics SDKs, or crash-reporting SDKs (as reflected in each release’s manifest and dependencies)
  • None of the apps upload your ledger or learning data to our servers; normal use does not require a network.

Permissions shown at install (release merged manifest)

Based on each app’s current release merged manifest (what the system shows when you install). Unless noted, there is no Internet, camera, or storage access permission.

  • Easy Ledger: The install list shows only one signature-bound internal permission (Android uses it to register in-app components; not something you grant separately). No Internet, camera, or storage permissions. Receipt photos are added only when you use the system camera or photo picker.
  • Group Matters: Same as Easy Ledger—only that internal signature permission, no Internet or camera.
  • C Week: That internal permission plus “view network connections” from the built-in video player library, so the player can tell whether the device is online. The app does not go online or upload your learning data. Lessons and videos ship inside the install package.

Children

We do not direct these apps at children or collect children’s data for our services. Because data stays on-device with no accounts, a parent or guardian can manage or uninstall the app on the device.

Security and device changes

  • On-device security depends mainly on your lock screen and system settings
  • Uninstalling usually deletes app data; back up before reinstalling or switching phones
  • Release-signed builds may not overwrite older debug or differently signed builds; uninstalling to fix a signature conflict deletes local data unless you backed up first

Website visit logs (etais.dev)

The marketing site etais.dev records page visit logs on the server (not requests for images, scripts, stylesheets, or other static assets). Log fields include: timestamp (UTC), IP address, page path and query string, HTTP status, Referer, browser User-Agent, Accept-Language, and approximate location from Cloudflare (country/region/city) plus ASN where available. Logs are stored in a Cloudflare D1 database, retained long-term (no automatic deletion), and used only for traffic statistics and abuse prevention—not sold or shared with advertisers. The Android apps themselves still do not collect or upload your in-app data.

The site also uses Cloudflare Web Analytics for aggregated traffic trends (separate from data handling inside the apps).

Third parties and open source

Download stores (GitHub Releases, Coolapk, Google Play, etc.) have their own policies separate from how data is handled inside the apps. Open-source libraries are used under their licenses; we do not use them to add tracking services.

Changes

If this policy changes in a material way, we will update the effective date on this page and note it in release notes or on the website where practical.

Contact

For privacy questions, email hi@etais.dev or visit etais.dev. You can also use Discussions / Issues on the relevant GitHub repository.
